# 灵感许愿瓶 · 星予

一个为设计师与创作者准备的私人灵感记录网页：把文字、图片或音乐链接写在桌面便签上，便签会折成一颗星星飞入许愿瓶；摇晃瓶子时，已有星星会相互碰撞，组合出新的创作提示。

[立即打开灵感许愿瓶](https://elenacheng2021-spec.github.io/xingyu-starjar/)

![灵感许愿瓶网页预览](public/og.png)

## 项目定位

这是一个“公开可访问、个人数据私有”的纯前端网页：任何人都能打开同一个网站，但每位访客的便签、星星与灵感记录只保存在自己的浏览器中，不会上传或与其他访客共享。

当前版本为第一阶段，重点验证“记录灵感 → 折成星星 → 投入瓶中 → 摇瓶重组”的核心体验。

## 已实现功能

- **完整插画场景**：英式田园原木书桌作为一张完整背景图展示，没有拆图、抠图或拼接。
- **透明热区交互**：便签、许愿瓶、台灯、画册和唱片册均由背景图上方的透明定位热区触发；悬浮时通过微光、轻抬或抖动提示可以互动。
- **桌面便签**：点击便签与羽毛笔，可记录文字、上传图片或填写音乐链接。
- **自动投星**：完成书写后无需单独点击“投递”，便签会自动折叠成纸星星，并带着微光轨迹飞入许愿瓶。
- **私人星星瓶**：星星使用 `localStorage` 保存在当前浏览器；刷新后仍然存在，不同访客之间互不影响。
- **瓶内动态**：新星星悬浮在上部，旧星星逐渐沉向瓶底，并伴随缓慢漂浮的星光粒子。
- **摇瓶生成灵感**：点击、拖动许愿瓶或使用“摇一摇”，随机抽取 2～3 颗已有星星，根据所选基调进行前端联想重组。
- **五种创作基调**：暖意、冷静、生长、叙事、奇想，让随机碰撞保留一定的人为方向选择。
- **台灯开关**：点击台灯在开灯与关灯之间切换，全局亮度平滑变化，关灯后许愿瓶保留微弱自发光。
- **公共旅行画册**：所有访客浏览同一组预设旅行照片，只读且不能上传修改。
- **公共 BGM 唱片册**：访客可以选择预设音乐、播放或暂停并调节音量，不能上传曲目。
- **基础无障碍与移动端兼容**：热区支持键盘操作，弹窗带语义标记，并提供基础窄屏适配。

## 数据与隐私

| 内容 | 保存位置 | 是否共享 |
| --- | --- | --- |
| 便签文字、压缩图片、音乐链接 | 访客浏览器 `localStorage` | 否，仅当前浏览器可见 |
| 星星与模拟生成的灵感 | 访客浏览器 `localStorage` | 否，仅当前浏览器可见 |
| 旅行画册 | 网页代码中的公共配置 | 是，所有访客相同 |
| BGM 列表 | 网页代码中的公共配置 | 是，所有访客相同 |

项目不包含后端、数据库、登录系统或外部大模型 API，也不需要任何 API Key。

## 技术实现

- HTML + Tailwind CSS CDN + 原生 JavaScript
- 单页静态网站，无 npm 构建依赖
- 一张完整背景插画 + `position: absolute` 透明热区
- 浏览器 `localStorage` 私有持久化
- GitHub Actions 自动部署 GitHub Pages
- 前端内置规则模拟 AI 灵感联想，不调用外部接口

```text
starjar/
├─ index.html                         # 页面、样式、交互与公共素材配置
├─ public/

│  └─ favicon.svg                     # 网站图标
└─ .github/workflows/deploy-pages.yml # GitHub Pages 自动部署
```

## 使用方式

1. 打开[公开网页](https://elenacheng2021-spec.github.io/xingyu-starjar/)。
2. 将鼠标移到桌面物件上，观察它们的互动反馈。
3. 点击便签，写下文字、图片或音乐灵感；完成后它会自动变成星星飞入瓶中。
4. 选择一个创作基调，再点击、拖动瓶子或按“摇一摇”获得新的组合提示。
5. 点击台灯、旅行画册或唱片册体验对应功能。

> 浏览器无痕模式、清理站点数据或更换设备后，本地星星不会自动同步。

## 替换公共素材

公共画册和 BGM 的配置集中写在 `index.html` 的脚本顶部：

- 修改 `TRAVEL_PHOTOS` 可替换固定旅行照片及说明。
- 修改 `BGM_TRACKS` 可替换预设曲目名称、描述与音频地址。
- 修改 `TONES` 可调整摇瓶时的创作基调、颜色与发散方向。

修改并推送到 `main` 分支后，GitHub Actions 会自动重新部署公开网页。

## 下一阶段建议

建议先完善核心闭环，再扩展社交或账号功能：

1. **星星回看与管理**：点击瓶内星星查看原始便签，支持搜索、标签、收藏与删除。
2. **可控的数据备份**：增加本地 JSON 导出与导入，让访客换设备时能主动迁移私人灵感，同时保持无后端架构。
3. **加强灵感重组**：根据颜色、时间、内容类型和关键词提供更丰富的组合模板，并明确展示本次碰撞来自哪些星星。
4. **替换个人公共素材**：把示例旅行图片和测试 BGM 换成站点作者拥有使用权的正式内容。
5. **细化动效与声音反馈**：完善便签折叠、星星落瓶、拖动摇晃、碰撞粒子和灯光过渡，并提供“减少动态效果”和静音选项。
6. **再评估账号与公开广场**：只有在确实需要跨设备同步或分享精选灵感时再引入后端；私人瓶与公共展示应保持清晰隔离，并默认保护隐私。
